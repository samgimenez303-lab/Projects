## PickleBook

[Open the PickleBook project](./picklebook)

A full-stack pickleball court reservation application built with React, Vite, Express, and MySQL. Includes customer, staff, and administrator portals, court booking, manual cash/GCash payment verification, receipts, and upcoming-game reminders.

See [PickleBook setup and verification instructions](./picklebook/README.md). Private environment files are excluded; the included `.env.example` contains placeholders only.
